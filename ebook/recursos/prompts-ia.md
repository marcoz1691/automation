# Biblioteca de prompts de IA — InmoSmart AI

**Recurso premium del ebook:** *Vende tu Propiedad Más Rápido con Inteligencia Artificial*  
**Marca:** InmoSmart AI  
**Total de prompts:** 110 (organizados en 11 categorías)  
**Herramienta sugerida:** ChatGPT, Claude u otro asistente con lenguaje natural

---

## Instrucciones generales de uso

1. **Copia y pega** el prompt completo en el chat de IA.
2. **Sustituye** los campos entre [corchetes] con tus datos reales.
3. **Verifica siempre** la información que te devuelva la IA:
   - Precios y comparables en portales locales actuales
   - Normas legales, tributarias y notariales [ADAPTAR AL PAÍS]
   - Datos técnicos de tu propiedad (m², antigüedad, gravámenes)
   - Estadísticas o tendencias de mercado [VERIFICAR FUENTE]
4. **No publiques** textos generados sin revisarlos: la IA puede inventar cifras o exagerar beneficios.
5. **Itera:** pide ajustes de tono, longitud o enfoque según el canal (portal, Instagram, WhatsApp).

**Prompt de verificación (úsalo después de cualquier respuesta importante):**

> Revisa tu respuesta anterior y señala qué afirmaciones debo verificar con fuentes externas (portales inmobiliarios, notario, avalúo, reglamento de copropiedad). Indica también qué datos faltan para que la respuesta sea precisa.

## Categoría 1: Investigación de mercado (10 prompts)

### Prompt 1.1 — Comparables iniciales
```
Actúa como analista inmobiliario en [ciudad, país]. Tengo una [casa/departamento/terreno] de [X] m², [N] recámaras, en [zona/colonia]. Precio deseado: [monto]. Ayúdame a definir qué criterios debo usar para buscar propiedades comparables en portales locales (ubicación, metraje, antigüedad, amenidades). Dame una checklist de búsqueda, no inventes precios. Al final, indica qué debo verificar manualmente en [nombres de portales locales].
```

### Prompt 1.2 — Tabla comparativa
```
Con los siguientes datos de comparables que yo recopilé de portales (pega aquí: precio, m², recámaras, zona, días publicado):
[PEGAR DATOS]
Organiza una tabla comparativa y explícame cómo interpretar si mi precio de [monto] está alto, bajo o alineado. No inventes comparables adicionales. Señala qué datos faltan para un análisis sólido.
```

### Prompt 1.3 — Precio por m² en zona
```
Explica cómo calcular y usar el precio por metro cuadrado en [zona, ciudad] para una propiedad de [X] m² construidos. Dame la fórmula y un ejemplo con números hipotéticos claramente marcados como ilustrativos. Indica que debo verificar rangos reales en portales locales antes de decidir.
```

### Prompt 1.4 — Demanda del comprador
```
Describe el perfil probable de comprador para una [tipo de propiedad] en [zona] de [ciudad], orientado al mercado latinoamericano. Incluye motivaciones, presupuesto probable (como rango hipotético), objeciones comunes y canales de búsqueda. Marca cualquier suposición que deba validar con un agente local o datos de mercado.
```

### Prompt 1.5 — Estacionalidad
```
¿Qué factores estacionales o económicos podrían afectar la venta de una propiedad residencial en [ciudad, país] en [mes/trimestre]? Responde de forma general para Latinoamérica sin inventar estadísticas. Sugiere fuentes donde puedo verificar tendencias locales [VERIFICAR FUENTE].
```

### Prompt 1.6 — Ventajas competitivas
```
Mi propiedad en [zona] tiene: [listar características reales]. Frente a otras publicaciones similares, ayúdame a identificar posibles ventajas competitivas y debilidades. Sé honesto si algo es poco diferenciador. No inventes amenidades que no listé.
```

### Prompt 1.7 — Análisis de anuncios competidores
```
Voy a pegar 3 titulares y descripciones de anuncios competidores en mi zona:
[PEGAR TEXTOS]
Analiza qué funcionan en copywriting (claridad, beneficios, llamadas a la acción) y qué errores evitar. Propón un titular original para mi propiedad sin copiar textualmente.
```

### Prompt 1.8 — Preguntas para agente o notario
```
Voy a vender por mi cuenta una propiedad en [país/ciudad]. Genera una lista de 15 preguntas inteligentes que debo hacer a [notario/abogado/agente inmobiliario local] sobre documentación, gravámenes, tiempos de cierre e impuestos. Marca [ADAPTAR AL PAÍS] donde corresponda.
```

### Prompt 1.9 — Mapa de servicios cercanos
```
Tengo una propiedad en [dirección o referencia de zona]. Sin inventar distancias exactas, sugiere qué categorías de puntos de interés debo mencionar en el anuncio (transporte, escuelas, comercio, salud) y cómo verificar distancias reales con Google Maps u otra herramienta.
```

### Prompt 1.10 — Decisión de bajar precio
```
Llevo [X] semanas con el anuncio publicado. Consultas: [número]. Visitas: [número]. Ofertas: [número]. Precio actual: [monto]. Ayúdame a evaluar criterios objetivos para decidir si conviene ajustar el precio. No me digas automáticamente que baje; lista señales, riesgos y qué datos debo revisar antes.
```

## Categoría 2: Preparación de propiedad (10 prompts)


### Prompt 2.3 — Reparaciones con mejor retorno
```

```

### Prompt 2.4 — Preparación por estancia
```

```

### Prompt 2.5 — Propiedad vacía
```
Mi propiedad está vacía. Sugiere estrategias de presentación (staging mínimo, staging virtual ético, iluminación, olor, temperatura) para que no se sienta fría en fotos y visitas. Recuerda mencionar que debo declarar staging virtual si lo uso.
```

### Prompt 2.6 — Propiedad habitada con familia
```
Vivo en la propiedad que vendo con [número] personas. Dame un plan de 7 días para mantenerla presentable para visitas con poco tiempo disponible. Incluye rutinas diarias y qué guardar antes de cada cita.
```

### Prompt 2.7 — Jardín, terraza o balcón
```
Tengo [jardín/terraza/balcón] en estado [describir]. Recomienda mejoras rápidas y de bajo costo para fotografía inmobiliaria. No sugieras obras mayores sin advertir costo y plazo.
```

### Prompt 2.8 — Neutralización de espacios
```

```

### Prompt 2.9 — Olor y ventilación
```
¿Qué protocolo seguir para eliminar olores comunes (humedad, cocina, mascotas, tabaco) antes de visitas? Recomienda soluciones realistas. Advierte contra trucos que engañan al comprador.
```

### Prompt 2.10 — Seguridad en preparación
```
Voy a recibir visitas en mi propiedad en [ciudad]. Genera un protocolo de seguridad para propietario que vende solo: identificación, acompañantes, objetos de valor, horarios. Marca [ADAPTAR AL PAÍS] para recomendaciones legales.
```
