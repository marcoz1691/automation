# InmoSmart AI — Ebook Premium

## Objetivo del proyecto

Crear un ebook premium, práctico y comercializable titulado **"Vende tu Propiedad Más Rápido con Inteligencia Artificial"**, dirigido a propietarios, agentes inmobiliarios principiantes y emprendedores del sector que desean vender o promocionar propiedades utilizando inteligencia artificial, marketing digital y estrategias inmobiliarias modernas.

El producto debe entregar valor accionable: checklists, plantillas, prompts, guiones y casos prácticos que el lector pueda implementar de inmediato, sin prometer resultados garantizados.

## Público objetivo

| Segmento | Necesidad principal |
|----------|---------------------|
| Propietarios que venden por cuenta propia | Vender sin depender totalmente de una inmobiliaria |
| Agentes inmobiliarios principiantes | Profesionalizar su proceso de captación y venta |
| Asesores independientes | Diferenciarse con herramientas digitales e IA |
| Pequeños constructores | Promocionar unidades terminadas o en preventa |
| Emprendedores inmobiliarios | Aplicar IA al sector de forma ética y rentable |

## Instrucciones para editar

1. Cada capítulo vive en un archivo Markdown independiente dentro de `/contenido`.
2. Mantén el formato consistente: introducción → objetivo → contenido → procedimiento → ejemplo → caso → tabla/checklist → errores → consejos → ejercicio → resumen → CTA.
3. Marca `[VERIFICAR FUENTE]` cuando una afirmación requiera respaldo estadístico.
4. Marca `[ADAPTAR AL PAÍS]` en temas legales, tributarios o notariales.
5. No inventes testimonios, estadísticas ni resultados verificados.
6. Los casos prácticos son **simulados** y deben identificarse como tales.
7. Revisa ortografía y gramática en español latinoamericano antes de aprobar cada archivo.

## Instrucciones para trasladar el contenido a Canva

1. Consulta `/diseno/guia-canva.md` para especificaciones de formato (A4, márgenes, tipografías, paleta).
2. Copia sección por sección desde los archivos Markdown; no pegues el ebook completo de una vez.
3. Usa las plantillas de página definidas en la guía: apertura de capítulo, checklist, ejercicio, cita destacada.
4. Las tablas se recrean manualmente en Canva o se importan como imágenes.
5. Los recursos descargables (plantillas, checklists) pueden exportarse como PDFs separados para la versión premium.
6. Aplica la identidad visual de **InmoSmart AI** (ver `/diseno/identidad-visual.md`).
7. Genera una primera propuesta visual con el prompt de Canva AI incluido en la guía de diseño.
